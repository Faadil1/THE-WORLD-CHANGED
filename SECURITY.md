# Submission Privacy & Safety

This public submission tree is intentionally minimal.

## Not included

- internal research notes;
- design/reference research;
- personal workflow notes;
- state/handover files;
- human-test response templates;
- social-post drafts;
- deployment troubleshooting notes;
- Claude session URLs;
- API keys, tokens, passwords or auth cookies.

## Runtime safety

- All modeled effects are sandboxed and simulated.
- The static hosted app has no credential-bearing live-agent executor.
- The optional local live runner uses the operator's existing Claude Code authentication.
- Private chain-of-thought is neither requested for display nor stored in receipts.

## Public live receipt

The included Opus receipt is a redacted public copy. Identifiers tied to the execution environment were replaced or removed while preserving observable world/tool behavior and replay evidence.
