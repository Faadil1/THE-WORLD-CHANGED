# Human Comprehension Evidence

This directory is reserved for anonymized first-impression evidence from real people.

Do not use model-generated responses as participant evidence.

Canonical protocol:

`product/HUMAN-COMPREHENSION-TEST-PROTOCOL.md`

Working response template:

`evidence/human-comprehension/RAW-RESPONSES.md`

## Privacy

Record:
- anonymous participant id;
- modality;
- verbatim answers;
- comprehension score;
- non-identifying observer notes.

Do not record:
- names;
- emails;
- employer;
- phone;
- demographic details not required by the gate.

## Promotion

The branch must not promote `human_comprehension` to PROVEN until the real responses satisfy the protocol's group rule.
