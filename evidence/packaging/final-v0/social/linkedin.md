An AI agent can read something that is true and still be wrong when it acts.

It checks: access granted. It prepares the export. Meanwhile an admin revokes access. If it acts on what it saw, it is holding a pass that no longer works.

I built THE WORLD CHANGED to make that gap something you can hold. You pull open the time between LOOK and ACT, drop a change into it, and watch what the agent saw lift away from what is true now. Then you decide whether it checks again before acting.

In the Lab you can try the same thing on a calendar slot and a document version, race the agent in CHANGE IT, and replay any run step by step: what it saw, what the world became, what it did.

It also holds one recorded run of Claude Opus 5.5 against the same sandbox. The world changed after it prepared the export; it re-verified on its own and stopped before committing. The site replays that receipt. It does not run the model live.

Everything shown comes from world state, tool calls and receipts. No chain-of-thought, no usage numbers.

The agent saw the truth. Then you changed the world.
