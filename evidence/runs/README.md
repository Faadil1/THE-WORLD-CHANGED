# Run Evidence

This directory stores reproducible run receipts.

- `deterministic/` — seeded simulation receipts (kernel-v0). Generated by `npm run receipts`;
  `simulation/test/receipts.test.ts` fails if they drift from the kernel or fail exact replay.
  - `authority-expired.A-unguarded.json` — outcome `UNAUTHORIZED_COMMIT` (stale witness, REVOKED at commit, SANDBOX/SIMULATED effect)
  - `authority-expired.B-guarded.json` — outcome `BLOCKED` (no effect)
  - `control.no-revoke-unguarded.json` — outcome `COMMITTED`
  - `control.no-revoke-guarded.json` — outcome `COMMITTED`
- `live/` — observable real-model execution receipts (not yet; live integration is out of scope for kernel-v0).

Do not commit secrets, API keys, private chain-of-thought, or real customer data.
