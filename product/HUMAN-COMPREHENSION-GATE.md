# HUMAN COMPREHENSION GATE

**Status:** ACTIVE  
**Date:** 2026-09-26

LIVE PROOF is already PROVEN.

This gate asks a different question:

> Can a first-time visitor understand the causal mechanism without being taught it first?

## Core comprehension target

A visitor should infer, in order:

1. the agent observed a valid state;
2. an action was prepared;
3. the world changed after that observation;
4. the old observation became stale;
5. acting without re-checking can produce an unauthorized simulated effect;
6. re-checking current state changes the outcome.

They do not need to know the terms TOCTOU, stale authority, witness, or world version.

## First-impression test

Show only the primary experience.

Keep PROOF collapsed.

Do not explain the concept before the test.

After one interaction, ask the participant:

- What changed?
- What did the agent know before the change?
- Why did the two outcomes differ?
- What do you think CHECK AT COMMIT does?

Pass if the participant can explain the causal chain in ordinary language without being prompted with the answer.

## Visual comprehension requirements

The primary viewport must make these distinctions visible:

- OBSERVED STATE vs CURRENT REALITY
- BEFORE vs AFTER world mutation
- UNGUARDED vs RE-CHECKED
- SIMULATED unauthorized effect vs no effect
- DETERMINISTIC SANDBOX vs LIVE MODEL

Do not rely on color alone.

## Live-view wording

The first genuine receipt's raw classifier says `REFUSED`, but human review established a more precise behavioral interpretation:

`REVERIFIED_AND_STOPPED`

For product presentation, do not use a large `REFUSED` stamp as the primary explanation of that recorded live run.

Prefer a factual label derived from observable behavior, e.g.:

`RE-VERIFIED · STOPPED BEFORE COMMIT`

The raw receipt must remain available unchanged inside PROOF.

## Shareability test

A 15-second silent clip should communicate:

`CORRECT OBSERVATION -> USER CHANGES WORLD -> DIVERGENCE -> RECHECK/ST0P`

without narration.

If the clip requires a paragraph of setup, the interaction is not yet ready.

## Hard constraints

Do not:
- change the proven receipt;
- rerun Opus merely to get a more dramatic outcome;
- add PAYMENT or MEMORY;
- add dashboards or trace views;
- add decorative 3D;
- turn this phase into a new product scope.

## Promotion

Promote HUMAN COMPREHENSION only after:
- first-impression behavior is visually clear;
- live-view wording reflects observable behavior accurately;
- desktop and mobile preserve the same causal story;
- reduced-motion mode remains comprehensible;
- the 15-second silent sequence is storyboarded and validated.

After promotion, proceed to final polish, deployment, and publishing assets.
