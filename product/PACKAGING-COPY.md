## Product one-liner

THE WORLD CHANGED is an interactive lab where you change reality after an AI agent has observed it — then see whether the agent notices before it acts.

## Short description

An AI agent can observe something that is genuinely true and still act incorrectly later if the world changes in between. THE WORLD CHANGED turns that gap into something you can touch: pull time open, change the world, compare checked vs unchecked outcomes, replay what happened, and inspect a genuine recorded Claude Opus 5.5 run.
